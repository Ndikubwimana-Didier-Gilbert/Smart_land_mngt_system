How It Works

1. Submit

Fill in your parcel and location details in the application form.

2. Review

Your application is reviewed by land administration staff.

3. Decision

The application status changes to approved or rejected.

4. Track

Check your application status anytime using your application ID.

Key Features

Parcel Registration

Register parcels with district, cell, and plot number details.

Ownership Records

Owners are linked to parcels using national ID or passport number.

Land Type Classification

Parcels are classified as residential, agricultural, commercial, and more.

Application Tracking

Applicants can check their status at any stage of the process.

Administrative Review

Admin staff process applications and update their status.

Secure Admin Access

Only registered administrators can manage parcels and applications.

About This System

LandTrack was built to make land registration easier to manage than paper-based records. Landowners can submit applications online, and administrators can review, approve, or reject them, keeping every parcel, owner, and application organized in one place.
